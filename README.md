# 🖥️ Site Web - Département Informatique EFREI

Ce projet est un site web vitrine moderne et interactif développé pour le **Département Informatique de l'EFREI** (Paris Panthéon-Assas Université). Il a été conçu pour présenter les formations, l'équipe pédagogique et la vie étudiante du campus.

## 📋 Présentation du projet
L'objectif de ce projet est de démontrer les compétences acquises en développement web Front-End (HTML5, CSS3, JavaScript) à travers une interface utilisateur (UI) soignée, ergonomique et représentative de l'image d'excellence de l'école.

## 🚀 Fonctionnalités principales
- **Navigation Intuitive** : Une barre de navigation fixe permettant d'accéder rapidement aux rubriques : Accueil, Cours & Formation, Équipe, Vie Étudiante, Contact et À Propos.
- **Carrousel Interactif** : Une section "Vie sur le campus" dynamique permettant de faire défiler les images des infrastructures de l'EFREI.
- **Design Responsive** : Mise en page adaptative garantissant une expérience optimale sur ordinateur, tablette et mobile.
- **Sémantique HTML5** : Utilisation rigoureuse des balises sémantiques pour un meilleur référencement (SEO) et une meilleure accessibilité.

## 📂 Architecture des fichiers
Le projet est structuré de manière professionnelle pour faciliter la maintenance :
- `/index.html` : Page d'accueil principale.
- `/html/` : Contient les pages secondaires (`a_propos.html`, `contact.html`, `cours_formation.html`, etc.).
- `/css/` : Dossier contenant la feuille de style `style.css`.
- `/js/` : Contient `script.js` pour les fonctionnalités dynamiques (carrousel, menus).
- `/image/` : Ensemble des ressources graphiques (logo EFREI, photos du campus, portraits de l'équipe).

## 🛠️ Technologies utilisées
- **HTML5** : Structure sémantique du contenu.
- **CSS3** : Mise en forme avancée (Flexbox, Grid, transitions et animations).
- **JavaScript (Vanilla JS)** : Logique d'interaction et manipulation du DOM.
- **GitHub** : Gestion de version et collaboration.

## 🎨 Design (UI/UX)
Le design respecte la charte graphique de l'EFREI avec :
- Une palette de couleurs dominée par le bleu et le blanc.
- Des cartes (cards) avec ombres portées (`box-shadow`) pour un effet de profondeur.
- Une typographie claire et lisible pour faciliter la lecture des informations pédagogiques.
